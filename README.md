# FitMe AI

Мобильное приложение для виртуальной примерки одежды.
Flutter (Android) → бэкенд FastAPI на ПК → модель FASHN VTON 1.5 на GPU в Kaggle.

## Что умеет

- **Примерка**: фото человека + фото вещи (верх, низ, платье) → результат от FASHN VTON 1.5.
- **Каталог**: добавить вещь по ссылке на товар (фото берётся автоматически) или загрузить своё фото.
- **Настройки вещи**: цвет (перекраска с сохранением теней), размер XS–XXL, посадка Slim/Regular/Oversize. Это примерная визуализация, а не точная размерная сетка бренда.
- **Параметры тела**: рост, вес, грудь, талия, бёдра. Фото человека подгоняется под эти пропорции до генерации.
- **2D-аватар**: вырезка человека с фона (rembg) и превью с параметрами тела.
- **Луки**: сохранение и удаление результатов.

## Первый запуск

1. Установите Python 3.11 или 3.12 и Flutter SDK, включите на телефоне отладку по USB.
2. Запустите `backend\setup_backend.bat`. Он создаст `.venv` и установит зависимости.
   Если `rembg` не установится, всё остальное будет работать, кроме вырезки фона для аватара.
3. Выполните `flutter pub get` в корне проекта.

## Каждый запуск

1. Откройте `KAGGLE/FitMe_FASHN_VTON_Kaggle.ipynb` в Kaggle и включите **GPU** и **Internet**, затем нажмите **Run All**.
2. Скопируйте строку `FITME_AI_URL=https://....trycloudflare.com` в конце вывода.
3. Подключите телефон по USB и запустите `START_FITME.bat`, вставив туда эту строку.
   Скрипт проверит Kaggle, запустит бэкенд на порту 8000, сделает `adb reverse` и `flutter run`.

Пока вы пользуетесь приложением, сессия Kaggle должна быть запущена. После перезапуска Kaggle URL меняется.

## FitMe v2: ноутбук = сервер, телефон без кабеля

1. Один раз: `INSTALL_PYTHON.bat` → `INSTALL_LOCAL_GPU.bat` (PyTorch + FASHN на вашей видеокарте).
2. Подключите телефон по USB и запустите `INSTALL_ON_PHONE.bat` — соберёт и установит приложение,
   потом сам запустит серверы. Кабель после этого можно отключить.
3. В следующий раз достаточно `START_LOCAL_GPU.bat`: GPU-сервер + бэкенд + Cloudflare-туннель.

Телефон сам находит ноутбук: дома — по Wi-Fi, вне дома — через интернет (туннель, как в Kaggle).
Адрес публикуется в приватный ntfy.sh-канал, доступ к серверу защищён ключом из `discovery.json`
(файл создаётся автоматически и не попадает в git).

**Примерка образа:** до 3 вещей за раз (например, брюки + футболка + куртка) — сервер надевает их
по очереди: низ → платье → верх. Качество (v3): 15 / 30 / 50 шагов (≈45 / 70 / 105 с на вещь на RTX 4060).

## FitMe v3: качество и выбор модели

- **Чёткость:** перед генерацией фото обрезается по человеку (больше пикселей модели уходит на тело),
  результат увеличивается Real-ESRGAN x4 и вклеивается обратно в исходное фото. Фон, лицо и волосы
  остаются вашими исходными пикселями в полном разрешении, меняется только одетое тело.
  Код — `gpu_server/enhance.py`, проверка — `SELFTEST_GPU.bat` (сравнение v2/v3 в `test_output/`).
- **Качество:** Быстро 15 / Баланс 30 / Максимум 50 шагов.
- **Выбор модели в приложении:** FASHN VTON 1.5 на ноутбуке (без лимита) или бесплатные облачные
  модели Hugging Face ZeroGPU: FASHN (облако), Leffa, FitDiT, IDM-VTON (только верх), OOTDiffusion.
  Облако даёт несколько минут GPU в день; с бесплатным HF-токеном (`SET_HF_TOKEN.bat`) — больше.
- **Фото человека:** выбранное в «Примерке» фото больше не перезаписывает аватар.
- Растягивание фото под мерки отключено (портило лицо и фон); включить: `FITME_BODY_WARP=1`.
- `CLOSE_EXTRA_WINDOWS.bat` закрывает лишние окна терминала, серверы остаются.

## Облачный режим без ноутбука (Hugging Face)

Бэкенд размещается на бесплатном Hugging Face Space, генерация идёт на бесплатном ZeroGPU,
а APK собирается с адресом этого Space. Пошаговая инструкция — в [DEPLOY_CLOUD.md](DEPLOY_CLOUD.md).

Бэкенд выбирает провайдер сам (`FITME_AI_PROVIDER=auto`): Kaggle/локальный GPU, если его URL задан и он онлайн, иначе Hugging Face Space.

## Другой адрес бэкенда

По умолчанию приложение обращается к `http://127.0.0.1:8000` (через `adb reverse`). Другой адрес можно задать так:

```
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:8000
```

## Веб-версия

Тот же код Flutter работает в браузере, сервер отдаёт сайт сам.

1. Один раз на компьютере с Flutter запустите `BUILD_WEB.bat`: сборка попадёт в `backend/app/web_app/`.
2. Запустите сервер как обычно (`START_LOCAL_GPU.bat`) и откройте ссылку `.../app/?key=...` из его окна.
   Ключ сохранится в браузере и исчезнет из адресной строки. Без ключа сайт предложит ввести его вручную.

Сайт открывается и по адресу Wi-Fi, и через интернет-туннель. На другой адрес бэкенда сборку можно
нацелить так: `flutter build web --base-href /app/ --dart-define=API_BASE_URL=https://...`.
Ключ `FITME_KEY` в веб-сборку не передавайте: файлы сайта доступны всем, у кого есть адрес.

### Размещение в облаке (Bult.ai)

В корне лежит `Dockerfile`: он сам собирает сайт и запускает сервер. В Bult.ai укажите репозиторий,
Dockerfile `./Dockerfile`, контекст `.` и постоянный диск с путём `/data`.
Переменные окружения сервиса:

| Переменная | Значение |
|---|---|
| `FITME_FIREBASE_CREDENTIALS_JSON` | всё содержимое файла сервисного аккаунта Firebase (секрет) |
| `FITME_FIREBASE_API_KEY` | значение `kFirebaseApiKey` из `lib/firebase_options.dart` |
| `FITME_OWNER_EMAIL` | почта создателя |
| `FITME_KAGGLE_TOPIC`, `FITME_KAGGLE_KEY` | `topic` и `key` из `backend/data/kaggle.json` (секрет) |

`FITME_API_KEY` в облаке не задавайте: иначе скачанное приложение не подключится.
Bult.ai не предоставляет GPU: примерки выполняет блокнот Kaggle из `KAGGLE_PRIVATE` (его создаёт `KAGGLE_GPU.bat`),
он должен быть запущен и приватен.

### Скачивание приложения с сайта

`BUILD_APK.bat` спрашивает адрес сервера, собирает APK и кладёт его в `web/downloads/FitMe.apk`.
После пересборки сайта на нём появляется кнопка «Скачать». Ключ `FITME_KEY` в такой APK не передавайте:
файл доступен всем.

Отличия от приложения: фото и настройки хранятся в браузере (IndexedDB), а кнопка «Камера» на компьютере
открывает выбор файла (камера телефона работает в мобильном браузере).
